# Requirements Analysis
This repository contains the (mostly `.tex`) code for the requirementy analysis of the `CodeX` project.

The project structure is based on the [template from the TVA institute](https://www.overleaf.com/read/xthqbwhtnzfb#8daff0) at KIT.

## Project structure
- `drawio/` contains `.drawio` files for the diagrams used in the documentation. To compile these, the scripts in `scripts` can be used.
- `figures/` contains the generated drawio figures in `figures/drawio/`, and ui drafts in `figures/ui/`.
- `common/` is a configuration directory that contains layout, metadata, and package configurations, as well as logos.
- `Pflichtenheft/` contains the `.tex` code.
